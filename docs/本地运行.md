# IndexTTS 本地运行说明

本机环境：Windows + PowerShell、`uv`、RTX 4080（16GB）、已有 IndexTTS-2 权重。

日常启动直接运行仓库根目录的 `start.ps1`。

```powershell
.\start.ps1
```

浏览器访问脚本打印的地址。默认先试 **7860**（Gradio / 官方默认）；被占用时自动换到 7861、7862……

## 首次准备

依赖已装过则跳过。未创建 `.venv` 时，在仓库根目录执行：

```powershell
uv sync --extra webui --default-index "https://mirrors.aliyun.com/pypi/simple"
```

Windows 上不要用 `--all-extras`（会装 DeepSpeed，容易失败）。只要 WebUI 用上面这条即可。

检查 GPU：

```powershell
uv run tools/gpu_check.py
```

## 模型

当前默认跑 **IndexTTS-2**，权重放在 `checkpoints/`，至少需要：

- `config.yaml`
- `bpe.model`
- `gpt.pth`
- `s2mel.pth`
- `wav2vec2bert_stats.pt`

辅助模型在 `checkpoints/hf_cache/`（w2v-bert、BigVGAN、CAMPPlus 等），首次启动若缺失会自动下载。国内网络建议保留：

```powershell
$env:HF_ENDPOINT = "https://hf-mirror.com"
```

`start.ps1` 已自动设置该镜像。

### 如需 IndexTTS-2.5

不要覆盖现有 `checkpoints/`。下载到单独目录：

```powershell
hf download IndexTeam/IndexTTS-2.5 --local-dir=checkpoints_2.5
```

或：

```powershell
modelscope download --model IndexTeam/IndexTTS-2.5 --local_dir checkpoints_2.5
```

2.5 额外需要 `codec.pth`、`multilingual_zh_ja_yue_char_del.tiktoken`。

```powershell
.\start.ps1 -Version 2.5
```

## 启动参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-Version` | `2` | `2` 或 `2.5` |
| `-Port` | `7860` | WebUI 端口；被占用时自动顺延到下一个空闲端口 |
| `-ModelDir` | `2` → `./checkpoints`，`2.5` → `./checkpoints_2.5` | 模型目录 |
| `-NoFp16` | 关闭 | 加上后使用全精度（更占显存） |

示例：

```powershell
.\start.ps1 -Port 7870
.\start.ps1 -Version 2.5
.\start.ps1 -NoFp16
```

## 等价手动命令

当前本机实际使用的启动命令：

```powershell
$env:HF_ENDPOINT = "https://hf-mirror.com"
uv run webui.py --version 2 --fp16 --port 7860
```

官方默认是 IndexTTS-2.5（全精度）：

```powershell
uv run webui.py
```

本机 16GB 显存建议加上 `--fp16`。2.5 在支持 BF16 的卡上会自动走 BF16。

## 说明

- 所有 `uv` 命令会自动使用项目 `.venv`，不要先手动 `activate`。
- 系统 Python 3.14 不能直接跑本项目；`uv` 会使用 3.10–3.11。
- 仓库根目录的 `uv.exe` / `uvw.exe` / `uvx.exe` 是误放文件，启动请用系统里的 `uv`。
